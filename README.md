# Rosa's Shopping Mall

Small mobile-friendly browser game prototype built with **Vite + React + TypeScript**.

## Gameplay

- Start at the mall entrance.
- Move on the grid to collect all shopping list items from the correct shop types.
- Reach the exit after collecting everything.
- Lower move count = better score.
- Share your result at the end.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import project in Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`
